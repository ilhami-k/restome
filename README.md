# RestoMe

Expo React Native restaurant ordering app.

## Run

Install Node.js 20.19.4 or newer, then run:

```bash
npm install
npm run start
```

Scan the QR code with Expo Go.

If Expo Go stays on the loading screen, run the tunnel start command instead:

```bash
npm run start:tunnel
```

## Scripts

- `npm run start`
- `npm run start:tunnel`
- `npm run ts:check`
- `npm test`
